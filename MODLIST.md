# Mod list (Forge 1.20.1)

Get every mod from CurseForge and pick the **Forge 1.20.1** file. Check the download
count and the version notes on each page. Create add-ons sometimes lag behind new Create releases.

## Required

| Mod | Why |
|---|---|
| [Create](https://www.curseforge.com/minecraft/mc-mods/create) | The factory |
| [KubeJS](https://www.curseforge.com/minecraft/mc-mods/kubejs) | Runs the Factory Ascension scripts (KubeJS 6 / 2001.x for 1.20.1) |
| [Rhino](https://www.curseforge.com/minecraft/mc-mods/rhino) | KubeJS dependency |
| [Architectury API](https://www.curseforge.com/minecraft/mc-mods/architectury-api) | KubeJS dependency |

## Factory and gear

| Mod | Why |
|---|---|
| [Create: The Factory Must Grow](https://www.curseforge.com/minecraft/mc-mods/create-industry) | Steel, oil, engines. Adds steel to the Ascension Core recipe and metals to the Exotic cluster. Make sure the 1.20.1 build matches your Create version |
| [Mekanism](https://www.curseforge.com/minecraft/mc-mods/mekanism) | MekaSuit, ore processing, extra metals for the Exotic cluster |
| [Tinkers' Construct](https://www.curseforge.com/minecraft/mc-mods/tinkers-construct) | Build-your-own weapons from factory alloys |
| [Create Enchantment Industry](https://www.curseforge.com/minecraft/mc-mods/create-enchantment-industry) | Liquid XP and automated enchanting. Check it supports your Create version |

## Carrying the loot

| Mod | Why |
|---|---|
| [Sophisticated Backpacks](https://www.curseforge.com/minecraft/mc-mods/sophisticated-backpacks) + [Sophisticated Core](https://www.curseforge.com/minecraft/mc-mods/sophisticated-core) | Upgradeable backpacks (up to netherite size) with pickup, magnet, filter and void upgrades, for hauling horde loot home |
| [Waystones](https://www.curseforge.com/minecraft/mc-mods/waystones) + [Balm](https://www.curseforge.com/minecraft/mc-mods/balm) | Optional. Fast travel between waystones; the pack adds cheaper Waystone, Warp Stone, Warp Dust and Warp Scroll recipes. Tested with 14.1.21 |
| [Tom's Simple Storage](https://www.curseforge.com/minecraft/mc-mods/toms-storage) | Auto-sorting storage: chests in a row join into one inventory with a scrollable, searchable Storage Terminal. More chests = more space. Tested with 1.20-1.7.1 |

## Things to fight

| Mod | Why |
|---|---|
| [L_Ender's Cataclysm](https://www.curseforge.com/minecraft/search?search=cataclysm) | Very hard bosses with endgame gear |
| [The Twilight Forest](https://www.curseforge.com/minecraft/mc-mods/the-twilight-forest) | Boss-by-boss dimension progression |
| [Ice and Fire](https://www.curseforge.com/minecraft/mc-mods/ice-and-fire-dragons) + [Citadel](https://www.curseforge.com/minecraft/mc-mods/citadel) | Dragons that grow with age |
| [When Dungeons Arise](https://www.curseforge.com/minecraft/mc-mods/when-dungeons-arise) | Huge structures full of loot |

## Quality of life

| Mod | Why |
|---|---|
| [JEI](https://www.curseforge.com/minecraft/mc-mods/jei) | Recipe lookup, shows all the Factory Ascension recipes |
| [Jade](https://www.curseforge.com/minecraft/mc-mods/jade) | See what's inside machines |

## Performance (recommended, especially on lower-end PCs)

| Mod | Why |
|---|---|
| [Embeddium](https://www.curseforge.com/minecraft/mc-mods/embeddium) | Much faster rendering (Sodium for Forge) |
| [ModernFix](https://www.curseforge.com/minecraft/mc-mods/modernfix) | Faster loading, less RAM |
| [FerriteCore](https://www.curseforge.com/minecraft/mc-mods/ferritecore) | Less RAM |
